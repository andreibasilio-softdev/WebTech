BASIC YET USEFUL HTML TAGS.

1. The bold tag is used to bold the text inside the tag.

2. The strong tag is used to make the text more important or holds a significance.

3. The italic tag is used to make the text inside an italic font.

4. The em tag is used to emphasize the text inside the tag.

5. The u tag is used to underline the text inside the tag.

6. The mark tag is used to highlight the text inside the tag.

7. The small tag is used to make the text inside smaller.

8. The del tag is used to strike through the text inside the tag.

9. The ins tag is used to underline the text inside the tag.

10. The sub tag is used to make the text inside a subscript.

11. The sup tag is used to make the text inside a superscript.
